# 📚 1만 시간의 법칙 - 1차 미니 프로젝트

> “연습은 어제의 당신보다 당신을 더 낫게 만든다.”

---

## 📌 프로젝트 소개

이 프로젝트는 **"1만 시간의 법칙"** 을 주제로 한 인터랙티브 웹페이지입니다.  
사용자가 전문가가 되기 위한 분야와 하루 훈련 시간을 입력하면, 총 몇 일이 필요한지를 계산해주는 간단한 도구입니다.

> 💡 1만 시간의 법칙이란?  
> 어떤 분야의 전문가가 되기 위해서는 최소 10,000시간의 훈련이 필요하다는 이론입니다.

---

## 🔧 사용 기술

- **HTML5**
- **CSS (반응형 포함)**
- **Vanilla JavaScript (미포함 상태이나 확장 가능)**
- **웹폰트**: GmarketSans, OTEnjoystoriesBA

---

## 🎯 주요 기능

- 사용자가 입력한 분야와 시간 기준으로 훈련 필요 일수 계산
- 반응형 디자인 (PC / 모바일 버튼 이미지 전환, 레이아웃 변경)
- 모달 팝업을 활용한 동기 부여 메시지 출력
- 커스텀 체크박스를 활용한 모달 구현

---

## 📸 화면 구성

- 인트로 텍스트와 명언
- 사용자 입력 폼
- 계산 버튼 및 결과 출력
- 훈련 시작 / 공유 버튼
- 모달 팝업 메시지
- 푸터 (저작권 안내)
